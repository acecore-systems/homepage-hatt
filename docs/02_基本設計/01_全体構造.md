# 全体構造

## 構成

| 区分                                | 役割                                                                   |
| ----------------------------------- | ---------------------------------------------------------------------- |
| Astro / UnoCSS                      | 作品、ブログ、制作情報の公開UIを生成する                               |
| Sveltia CMS                         | ブログ、タグ、著者、モデリング項目、キャンペーン、サイト設定を編集する |
| Cloudflare Access / Pages Functions | 編集者認証とCMS保存時の検証を行う                                      |
| GitHub App                          | 許可済みコンテンツだけを`main`へ保存する短期tokenを発行する            |
| Cloudflare Pages                    | GitHub連携で公開し、Pagefindの検索indexを生成する                      |
| D1 / Turnstile / Email              | コメントと無料体験申し込みの保存・保護・通知を担う                     |

## 保存から公開まで

1. CMSが同一originのFunctionsへ保存要求を送る。
2. Functionsが対象path、コンテンツ、メディア、参照、最新HEADを検証する。
3. GitHub Appが検証済みの変更を`main`へ保存する。
4. Cloudflare PagesのGitHub連携がproduction公開を開始する。
